# 📚 StudyBuddy – A Web-based Study Assistant

StudyBuddy is a **full-stack MERN (MongoDB, Express, React, Node.js)** web application designed to help students manage their study sessions, events, and progress efficiently — all in one place.

---

## 🚀 Features

- 🧠 **User Authentication**
  - Secure login and registration using MongoDB and JWT
- 📅 **Dashboard Overview**
  - Displays study stats, upcoming events, and recent activities
- 🕒 **Event & Study Session Management**
  - Add or track study sessions, events, and assignments
- 📊 **Analytics and Progress**
  - Visualize study performance and history
- 💾 **Persistent Storage**
  - User data and updates stored dynamically in MongoDB
- 🎨 **Modern UI**
  - Built using Tailwind CSS for clean and responsive design
